<font size="4"><p><b>Welcome to Q4OS</b>, fast and powerful operating system focused on long-term stability, reliability and classic style user interface.</p><p>Q4OS is installed as a very basic and clean desktop environment with the minimal software kit. Now it's the right time to adjust your new desktop, you might want to make use of tweaking shortcuts below.</p></font>

---
Run desktop profiler
<font size="4"><p>Desktop Profiler will automatically install and configure set of recommended Applications and tools, all in single click.</p><p>You will be allowed to select between different desktop profiles.</p></font>

---
Install applications
<font size="4"><p>You will be directed to Q4OS web resources to download and install standalone useful applications.</p></font>

---
Install proprietary codecs
<font size="4"><p>Run an interactive script to install extra collection of professional quality codecs.</p><p>Media players such as VLC or Mplayer make use of these codecs in order to provide support for playback of DVD and multimedia files encoded through these codecs.</p></font>

---
Screen scaling
<font size="4"><p>Resize fonts and icons to adjust them according to the current screen resolution and make them more readable.</p></font>

---
Set autologin
<font size="4"><p>Bypass login screen and login without entering your password after the system boot.</p></font>

---
Switch start menu
<font size="4"><p>Switch to alternative Kickoff Start menu.</p><p>Well arranged, modern style start menu offers search bar, favorites tab, history and more.</p></font>

---
Hardware info
<font size="4"><p>Well arranged system hardware information.</p></font>

---
Desktop effects
<font size="4"><p>Clicking this button, you will turn desktop smoothing and beautifying effects on.</p><p>Note, desktop effects will work flawlessly on modern hardware only, it's not recommended to use it with legacy hardware. A short system testing will be performed to ensure the hardware is ready to accept the configuration.</p></font>
